# Green systems / visual references

The direction uses phosphor green, near-black, quiet code columns, signal paths, and original SVG line studies. The Matrix's green code imagery is the mood reference. The illustrations interpret the referenced objects as decorative portfolio artwork.

| Study                          | Reference and distinguishing details                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Raspberry Pi 5                 | [Official product photographs](https://www.raspberrypi.com/products/raspberry-pi-5/) and [mechanical drawing](https://pip-assets.raspberrypi.com/categories/892-raspberry-pi-5/documents/RP-008347-DS-1-raspberry-pi-5-mechanical-drawing.pdf?disposition=inline). Rectangular board, four mounting holes, 40-pin header, processor and I/O chips, stacked USB ports, Ethernet, and edge connectors.                                                                                     |
| Raspberry Pi Camera Module 3   | [Official camera page](https://www.raspberrypi.com/products/camera-module-3/) and [standard mechanical drawing](https://datasheets.raspberrypi.com/camera/camera-module-3-standard-mechanical-drawing.pdf). Compact board, four mounting points, central autofocus lens assembly, and ribbon connector.                                                                                                                                                                                  |
| BMW M50B25                     | [Haltech's engine reference](https://support.haltech.com/portal/en/kb/articles/m50-engine) and [BMW engine technology training manual](https://bmwtechinfo.bmwgroup.com/tech_training_manual/ST501%20Engine%20Technology.pdf). Top-down interpretation with six intake runners, long cam cover, six ignition positions, oil cap, and accessory outlines. This is the non-TU M50B25 direction, without inventing an M-power badge or individual throttle bodies.                          |
| Compact defense drone          | [Skydio X10D photographs](https://www.skydio.com/x10d) and [technical specifications](https://www.skydio.com/x10d/technical-specs). A visual study of a compact reconnaissance quadcopter: four arms, three-blade rotors, central body, and sensor pod. No weapon or functional design information is depicted.                                                                                                                                                                          |
| BBS RS                         | [BBS company history](https://www.bbs.com/en/company/history), [BBS USA background](https://www.bbs-usa.com/about/), and [split-rim component reference](https://www.srrhardware.com/products/bbs-16-17-34-bolt-step-up-barrel). The classic RS is a three-piece design. The drawing separates inner barrel, cross-spoke center, and outer lip along one axis with a perimeter fastener ring. It is not the later two-piece Super RS.                                                    |
| Lava Spine / World of Warcraft | User confirmed Lava Spine. No Gladiator rank or ownership claim is made.                                                      |
| Fishing setup                  | [Shimano NASCI schematic](https://www.shimanofishingservice.jp/img/product/parts/03569.pdf), [Rapala Original Floater](https://www.rapala.co.uk/uk_en/original-floater?childSku=022677001050), and [Maine's rainbow-trout identification reference](https://www1.maine.gov/ifw/fish-wildlife/fisheries/species-information/rainbow-trout.html). | Matrix mood                    | [The 1999 poster reference](https://www.impawards.com/1999/matrix_ver2.html). Black field, luminous green, digital texture; no film poster imagery is embedded.                                                                                                                                                                                                                                                                                                                          |

Research checked November 2, 2026. External photographs and drawings serve as references only; the site bundles its own SVG geometry, with no remote image requests or copied product photography.

The diagram components are in `src/components/ui/EngineeringDiagram.jsx`. The backdrop is decorative and hidden from assistive technology. The workbench provides readable captions. Its floating layers and signal animation pause offscreen, in hidden tabs, and when motion is disabled. Portfolio text uses at least 14px; body copy is 16–18px. Miniature interface illustrations are decorative, not reading content.
